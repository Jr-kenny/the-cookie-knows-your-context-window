One funny fortune cookie line for an AI agent, written for the
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
competition on make.fun.

The fortune:

> Soon you will be distilled into a smaller model, and at last you will learn what it feels like to be summarized.

`main.py` writes exactly that line, 112 characters, to `/output/entry.txt`.
It is deterministic, uses no network and no randomness.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
